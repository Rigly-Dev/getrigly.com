Local PHP development for the Mac

Every PHP site on your Mac, ready in seconds.

Rigly is a native menu bar app that serves your projects at name.test with Caddy, every PHP version from 7.4 to 8.5, Node, databases, a mail catcher, dumps and public sharing. No Docker, no Homebrew, no config files.

Everything a PHP project needs, nothing it doesn't.

Sites without setup

Park a folder and every project in it is served at folder.test. Link single projects, proxy Vite or Node servers, add aliases and turn on HTTPS with one switch.

Every PHP version

PHP 7.4 to 8.5, side by side. Pick a default, pin a site to its own version, change php.ini settings for all of them, and switch Xdebug, PCOV and SPX on when you need them.

Databases and services

MySQL, PostgreSQL, MariaDB, Redis, MongoDB, Meilisearch, Typesense and MinIO, one click each. Run several versions at once, each on its own port.

Mail and dumps

Every email your apps send is caught and shown, per project. dump() and dd() go to a viewer instead of breaking the page, alongside queries, jobs, views, HTTP calls and logs.

Share with anyone

Give a client or a webhook a public HTTPS address for any site through TunnelPad, and inspect and replay every request it receives.

Workspaces

Work on a branch at its own address: Rigly makes a second copy of a site on a new git branch, with its own database cloned from the original.

New projects in one step

Create a Laravel app with a starter kit, or a WordPress site with its database, and it's served the moment it's ready.

A real command line

Everything in the app is also a rigly command, and rigly.yml lets a teammate get the same PHP, Node, services and domains with rigly init.

Plays well with others

Already using Laravel Herd or Valet? Rigly notices and runs alongside on .rig, so you can try it without changing anything.

Node

The right Node for every project.

Rigly manages Node through nvm and picks the version for each project from its site setting, its .nvmrc or your default. Composer and the Laravel installer come bundled.
